========================================
  논문 리더 — 사용법
========================================

이 파일이 들어 있는 폴더가 프로젝트 폴더입니다.
GitHub : https://github.com/gkrqntjdgus1234/paper-reader


========================================
 1. 실행하기  ★ 이것만 알면 됩니다
========================================

  프로젝트 폴더 안의

        논문 리더.bat

  파일을 더블클릭하면 됩니다. 브라우저가 자동으로 열립니다.

  * 검은 창이 하나 뜨는데, 그게 프로그램 본체입니다. 닫으면 꺼집니다.
  * 바탕화면에 두고 쓰고 싶으면:
      "논문 리더.bat" 우클릭 → 보내기 → 바탕 화면(바로 가기 만들기)
      (파일 자체를 옮기지 말고 "바로 가기"를 만드세요. 옮기면 안 켜집니다.)


========================================
 2. 논문 넣기
========================================

  프로그램을 켜면 맨 위에 이런 칸이 있습니다:

        ＋ 논문 PDF 추가

  여기에 PDF 파일을 끌어다 놓거나, 눌러서 파일을 고르면 됩니다.
  여러 개를 한꺼번에 넣어도 됩니다.

  - "한국어로 번역하기" 체크를 끄면 원문만 만듭니다 (훨씬 빠름)
  - 진행 상황이 화면에 나옵니다. 끝나면 책장에 자동으로 나타납니다.
  - 창을 닫아도 작업은 계속됩니다. 다시 열면 진행 상황이 보입니다.

  걸리는 시간:
      보통 논문        2~4분
      수식 많은 논문   페이지당 1~2분 (33쪽이면 40분 이상)

  ※ 논문당 딱 한 번만 하면 됩니다. 그 다음부터는 즉시 열립니다.


========================================
 3. 읽기
========================================

  책장에서 논문을 누르면 열립니다.

    ← →  Space       페이지 넘김 (화면 좌우 끝 클릭도 됨)
    Home / End       처음 / 끝
    t                번역 <-> 원문
    b                북마크
    Ctrl+F           이 논문에서 찾기
    글자 드래그      하이라이트 (메모도 가능)
    하단 A- A+       글자 크기

  * 읽던 자리, 북마크, 하이라이트는 자동 저장됩니다.
  * 책장 맨 위 검색창 = 모든 논문에서 찾기 (원문·번역 둘 다)


========================================
 4. 절대 하지 말 것
========================================

  * .env 파일을 GitHub 에 올리지 마세요
      -> DeepL 키가 전 세계에 공개됩니다.
      -> 평소대로 두면 자동으로 제외되니 신경 안 써도 됩니다.

  * 아래 파일을 지우지 마세요:
      data\.translation-cache.json   번역 기록. 지우면 같은 문장을 다시 번역해서
                                     DeepL 한도를 또 씁니다.
      data\reader.sqlite3            읽던 위치·북마크·하이라이트.

  * data\ 안의 논문 폴더를 지우면 그 논문은 다시 넣어야 합니다.
    (번역은 캐시 덕분에 한도를 다시 쓰지 않습니다)


========================================
 5. 문제가 생기면
========================================

  * 더블클릭했는데 창이 떴다가 바로 꺼진다
      -> 창에 나온 안내대로 아래를 한 번 실행하세요:
         (프로젝트 폴더에서 주소창에 cmd 입력 후)
             py -3.12 -m pip install -r requirements.txt

  * "포트 5000 이 사용 중" 이라고 나온다
      -> 이미 켜져 있는 겁니다. 브라우저에서 localhost:5000 을 열어보세요.

  * 번역 버튼이 회색이고 안 눌린다
      -> 그 논문을 번역 없이 넣은 겁니다.
         "한국어로 번역하기" 를 켠 채로 같은 PDF 를 다시 넣으면 됩니다.

  * 수식이 빨간 글씨로 보인다
      -> PDF 에서 수식을 읽는 AI 가 가끔 틀립니다. 그 수식만 그렇고
         나머지는 정상입니다. 원문 PDF 를 보는 수밖에 없습니다.

  * 설치 직후 첫 실행이 한 번 실패한다
      -> Windows 보안 기능이 새 프로그램을 잠깐 막는 것입니다.
         고장이 아니니 다시 실행하면 됩니다.


========================================
 6. DeepL 한도
========================================

  한도    : 계정마다 다릅니다 (무료는 월 50만 ~ 100만 자)
  논문 1편: 3~4만 자  ->  한 달에 20~30편 정도

  지금 얼마나 썼는지는 논문을 넣을 때 검은 창에 나옵니다.
      DeepL 사용량: 39,319 / 1,000,000 자 (3.9%)

  같은 문장은 저장해뒀다가 재사용하므로 두 번 번역하지 않습니다.


========================================
 7. 코드를 고쳐서 GitHub 에 올릴 때
========================================

  (평소에는 할 일 없습니다. 코드를 손볼 때만)

  프로젝트 폴더에서 cmd 를 열고:

      git add -A
      git commit -m "무엇을 왜 바꿨는지"
      git push

  * 폴더에서 파일을 고쳐도 GitHub 에는 자동으로 안 올라갑니다.
    위 3줄을 해야 반영됩니다.


========================================
 8. 다른 사람이 이 코드를 받아 쓸 때
========================================

  각자 자기 DeepL 키가 필요합니다 (내 키는 GitHub 에 없습니다).

      git clone https://github.com/gkrqntjdgus1234/paper-reader.git
      cd paper-reader
      pip install -r requirements.txt
      copy .env.example .env
      (.env 를 열어 자기 DeepL 키를 넣는다)

  키가 없어도 원문 읽기는 됩니다. 번역만 안 될 뿐입니다.
